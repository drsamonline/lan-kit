lan-kit

The shared LAN core: a local room with a real-time channel over Server-Sent Events + POST. Zero dependencies. MIT.

Open the client demo Source

No WebSocket lib

SSE for server → client, POST for client → server. Nothing to bundle.

Host + client

createHost() in Node; Lan.client() in the browser.

Room codes

Short, unambiguous codes; a URL helper for the current LAN.

Offline by design

Runs on a Wi-Fi network with the internet unplugged.

Transport only — not a security boundary. Add your own room check and never send secrets.
